## 二、如何运行

1. **最简单**：直接双击 `index.html`（`file://` 协议即可，图片为相对路径，无需服务器）。
2. **推荐**：在本目录执行 `python -m http.server 8123`，浏览器打开 `http://127.0.0.1:8123/index.html`，可避免个别浏览器对 `file://` 的限制。
3. 兼容：手机竖屏 / 电脑横屏，触屏与鼠标均可操作（拖拽、点击、长按）。

## 三、替换素材

所有路径集中在 `index.html` 的 **配置区（模块一 CONFIG）** 顶部 `ASSETS` 对象，改这里即可，无需改动逻辑：

```js
const ASSETS = {
  liang: [ {img:'assets/liang_s1.jpg', name:'小难梁'}, ... ],  // 模式一五阶
  liangXipi: 'assets/liang_xipi.jpg',   // 超频形态
  liangZi:   'assets/liang_zi.jpg',     // 重启训练形态
  whale: { loli, girl, lady, eat, full },
  food:  { rice, riceSmall, gpu },
  bug:   'assets/bug.jpg'
};
```

道具（芯片/算力卡）在 `ITEMS` 数组里配置 `{ id, name, icon, value, weight, rare, heat }`，
按 `weight` 权重随机刷新到传送带；`value` 为算力，`heat` 为过热累积值。

### 图片尺寸建议

| 类型 | 建议尺寸 | 格式 | 说明 |
| --- | --- | --- | --- |
| 角色立绘（梁文峰/鲸鱼娘） | 768×1024 或 1024×1024 | JPG / PNG | 页面按 `aspect-ratio: 3/4` 裁切，主体尽量居中、头部留白 |
| 道具（芯片/算力卡/食物） | 256×256 | 透明底 PNG | 传送带与食物栏均按 `object-fit: contain` 展示 |
| Bug / 特殊道具 | 256×256 | 透明底 PNG | 权重调低即可控制出现概率 |

### 进化阶段配置

- 模式一：`STAGES_M1`（5 阶段）—— 每阶段含 `liang / whale / liangName / whaleName / quota（算力阈值）/ 台词库 / laser（AGI 镭射眼）`。
- 模式二：`STAGES_M2`（3 阶段）—— 每阶段含 `img / name / tag / 台词库（eat、gpu、head、belly、long、idle）`。

新增阶段只需往数组里追加对象，UI 与数值会自动适配（`quota` 设为 `Infinity` 表示最终阶段）。

## 四、接入真实音效

`SOUNDS` 配置 + `playSound(name)` 已预留，文件缺失时静默失败不报错：

```js
const SOUNDS = {
  eat:'assets/sfx/eat.mp3', evolve:'assets/sfx/evolve.mp3', error:'assets/sfx/error.mp3',
  click:'assets/sfx/click.mp3', bgm:'assets/sfx/bgm.mp3'
};
```

做法：新建 `assets/sfx/` 目录，放入同名文件即可自动生效；主菜单「音效：开/关」可切换。
如需用 WebAudio 合成音（免文件），把 `playSound` 内部改为 Oscillator 播放即可，调用点无需改动。

## 五、接入 Stable Diffusion 生成图

接口位置就是 `ASSETS` 与 `STAGES_M1 / STAGES_M2` 两个配置对象：

1. 用 SD 出图后按命名规范放入 `assets/`；
2. 修改 `ASSETS` 中对应路径（或只替换同名文件，代码零改动）；
3. 若新增分化形态（例如「泳装鲸鱼娘」），在 `STAGES_M2` 追加一个阶段对象并设置 `img` 即可，
   好感度满 100 会自动走 `evolveM2()` 的换装演出。

建议出图时固定 seed 与角色描述词，保证五阶立绘风格一致；`GameState.seed` 已作为随机种子字段预留。

## 六、v2 升级要点（手感 / 特效 / 动画 / 性能）

## 九、全局收尾 v5（音效 / 存档 / 移动端 / 设置 / 成就）要点

## 十一、v6 视觉高保真重构（抠图立绘化 + 芯片映射 + 进度条修复）

**素材接口（最高优先级）**
- `const BASE_PATH = './images/';` —— 把你的原图（梁文锋真人照、蓝发鲸鱼娘、芯片图）直接放进 `./images/` 即可生效。
- 找不到时自动回退：`./assets/` → `./素材包/模式一：梁文峰成长/` → `…/模式二：鲸鱼娘成长/` → `…/模式一：芯片和算力卡/` → `…/模式一：白饭和鱼/`。
- `ALT_NAMES` 内置「英文文件名 ↔ 素材包中文文件名」映射（如 `a100.png ↔ 英伟达A100.png`），中文原图也能兜底命中。
- 启动时 `AssetLoader.detect()` 先探测 `./images/` 是否有图，避免批量 404。

**ImageProcessor（抠图 + 立绘化，绝不重绘五官）**

## 十三、BUG FIX #5：模式一悬浮鲸鱼娘看不见 / 不互动

**根因**：`.whale-float` 旧定位 `top:-6%; right:-14%`，把整个悬浮窗推到舞台（视口）右侧之外，配合 `body{overflow:hidden}` 被整体裁掉 —— 鲸鱼娘、模型名标签、气泡台词因此全不可见。

**修复**
1. 定位改为锚定在梁文峰右侧：`left:calc(50% + clamp(84px,15vw,150px)); top:2%; right:auto; z-index:6`，并补齐 `≤900px`、`≤640px` 两档媒体查询（旧值 `right:-4%` 同样溢出）。
2. 新增 `ensureWhaleVisible()`：`renderMode1()` 与 `window.resize` 时运行，用 `getBoundingClientRect` 比对舞台边界，越界即把悬浮窗拉回可视区；并兜底 `display:none / visibility:hidden / opacity:0` 的异常。
3. 抠图安全闸：`chromaKey()` 擦除超过 **62%** 像素即判定失败并保留原图（防止角色被整个擦没）；`cutout()` 在去底失败时重绘原图，绝不产出空白立绘。
4. 互动更易察觉：普通 / 散热道具 → 眨眼 + 外框高亮 `.talk-pulse` + 气泡 2.4s；稀有道具 → 跳跃欢呼 + 爱心粒子 + 音效 + 气泡 2.6s（含「爸爸好强！」）。

## 十四、v7 微调：气泡右置 + 鲸鱼娘白底透明化

1. **互动气泡改到鲸鱼娘右侧**：`#whaleBubble1` 由头顶居中改为 `left:100%` 贴在右侧，并显式写 `width:max-content`（绝对定位的收缩宽度会被父容器夹成 0，导致气泡被压成一字一行的细条）+ `max-width:min(11rem,30vw)` + 允许换行。新增 `placeWhaleBubble()`：右侧空间不足 → 加 `.flip` 翻到左侧；两侧都不足 → 退回右侧并就地收窄。`bubble()` 对 `id==='whaleBubble1'` 自动调用，普通 / 稀有 / 进化气泡全部生效。
2. **白底透明化（三重保障）**：
   - 去底安全闸由「擦除 > 62% 判失败」放宽到 **> 90%** —— 白底素材 70%~85% 都是背景，旧阈值会把正确的去底判成失败并保留白底（白底残留的主因）。
   - 新增 `ImageProcessor.whiteKey()` + `borderOpaque()`：漫水去底后若四周仍不透明，再清掉所有接近纯白（≥236）的像素，立绘与游戏深色背景同步。
   - CSS 兜底：新增 SVG 滤镜 `#whiteKeySoft`（`alpha = 18 - 6×(r+g+b)`，纯白恰好变透明，亮度 ≤0.94 完全保留），仅作用于 `img[data-cut="0"]`（画布去底失败，如 `file://` 打开导致画布被污染时生效）。

## 十五、BUG FIX #7：立绘周围的大块黑底（遮挡梁文峰）

**现象**：鲸鱼娘立绘四周围着一整块不透明黑矩形，压住旁边的梁文峰。

**根因**：用 `file://` 直接打开时画布被污染（`getImageData` 抛 SecurityError），canvas 去底必然失败 → `data-cut` 停在 `0` → 走 CSS 兜底滤镜 `#whiteKeySoft`。而 SVG filter 默认滤镜区域是元素 bbox 外扩 `-10% ~ 120%`，区域内「透明像素」输入为 `(0,0,0,0)`，代入 `alpha = 18 - 6×(r+g+b)` 得 18，钳制为 1 → 整块滤镜区域被涂成不透明纯黑。

**修复**
1. `<filter>` 加 `x="0" y="0" width="100%" height="100%"`，滤镜区域锁死为元素自身 bbox，不再向四周扩展，黑框消失。
2. 追加 `<feComposite in="keyed" in2="SourceAlpha" operator="in"/>`，元素范围之外一律透明。
3. 兜底滤镜只作用于鲸鱼娘（`#whaleImg1` / `#whaleImg2`），梁文峰真人照片卡保持原样。
4. 两个鲸鱼娘 `img` 初始带 `data-cut="0"`，滤镜首帧生效，不再先闪白底。

> ⚠️ `file://` 下浏览器禁止读取画布像素，只能靠 CSS/SVG 去底；想要 canvas 精修去底（更干净的边缘），请用本地服务器打开，例如在本目录执行 `python -m http.server 8123` 后访问 `http://127.0.0.1:8123/index.html`。

## 十六、BUG FIX #9：小难梁照片被抠花（内嵌版 / http 下才出现）

**现象**：同一张「小难梁」立绘，`file://` 直接读 `assets/` 时显示为清晰的证件照卡片；换成内嵌 `data:` 图片的**单文件版**后，照片被抠掉白底 —— 衬衫、领带、背景板一起消失，边缘糊出黑斑，卡内「小难梁」名牌残缺。

**根因**：`ImageProcessor.upgrade()` 对 `cyber`（梁文峰）也执行 canvas 去底。

- `file://` 读本地文件 → 画布被污染 → 去底失败 → 保留原图（看起来反而正常）
- 内嵌 `data:` 图不污染画布 → 去底真的执行 → 白底证件照被抠坏

与 `#whiteKeySoft` 注释里的设计意图（"梁文峰的真人照片卡保留原样，只有鲸鱼娘立绘走 CSS 兜底"）矛盾。

**修复**：`upgrade()` 遇到 `cyber` 直接置 `data-cut='0'` 返回，不做像素去底；照片卡只保留霓虹框 + 代码雨外壳。只有鲸鱼娘插画（`anime`）继续走 canvas 去底。两种打开方式（`assets/` 与内嵌单文件）视觉一致。

## 十七、BUG FIX #8：拖拽投喂「判定圈已高亮却判不中」（自动试玩发现）

**现象**：快速拖拽（一下甩到鲸鱼娘头上就松手）时，判定圈明明已高亮成红色"可投喂"，松手后道具却弹回传送带、不加算力、连击被打断。

**根因**：`DragSystem.move()` 用**目标位置** `d.tx/d.ty` 决定判定圈是否高亮，`up()` 却用 **lerp 过程中的当前位置** `d.x/d.y` 判定命中。代理元素以 `lerp(0.35)` 平滑跟随，快甩时代理还停在传送带附近，于是"看起来能中、实际不中"。自动化测试实测：快甩 **0/4** 命中，常规拖拽 **4/4** 命中。

**修复**
1. `up()` 改用 `d.tx/d.ty` 判定，与高亮保持同一坐标（修复后实测 **4/4**）。
2. 命中后的粒子 / 飘字生成点同步改为松手位置，视觉与判定一致。
3. `ComputeSystem.feed()` 开头加数据兜底：`!def || !isFinite(def.value)` 直接 return，避免 `value` 缺失时被 `Math.round(undefined*mul)` 写成 NaN（NaN 会写进存档且不可逆）。
